Files:
- index.html
- assets/businessmistri-logo.png

Publish on the existing GitHub Pages repository:
1. Open the repository: https://github.com/sanneysharma/businessmistri
2. Open the repository's main page.
3. Choose Add file > Upload files.
4. Upload index.html and the assets folder (including businessmistri-logo.png).
5. Commit changes to the main branch.
6. Wait a few minutes, then open https://businessmistri.com

The existing custom domain and DNS setup should be left unchanged.
Contact email used on the page: businessmitri@gmail.com
